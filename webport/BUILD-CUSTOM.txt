Install requirements.txt. Put your USA ROM here as zelda3.sfc.
Run python assets/restool.py --extract-from-rom.
Copy custom-dialogue.txt over assets/dialogue.txt, then run python assets/restool.py.
The generated src/rt_torch_placements.h is included; to regenerate it from
extracted room/overworld YAML, run python generate_torch_placements.py.
Build all src/*.c and snes/*.c through run_with_tcc.bat (Windows) or make (Linux).
Do NOT define DWA_TEST for release builds. DWA_TEST enables the automated
playthrough, UI pixel preservation, and gameplay RAM checks in main.c.
DWA_TEST can load an entrance with RT_TEST_ROOM (e.g. 4=castle, 51=Hera).
Standalone regression tests: gcc -O2 -I. validation/ray_lighting_test.c -lm -o ray-test
Run those tests in a temporary folder: they create/remove ray-lighting.cfg.
The new PPU globals are rendering-only and do not change snapshot structure.
The prologue still uses save offsets 0x4e0/0x4e1. Lighting changes no game RAM.
